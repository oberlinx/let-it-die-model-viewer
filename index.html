LET IT DIE Fighter Models

The game never shows a name for its 16 fighter bodies. This page pairs each internal model id with what it looks like, rendered from the game's own meshes and textures.

Labels such as "Female 3" match the model picker in the LET IT DIE save editor; the id underneath is the master_body key stored in the save. Renders show the base body in its reference pose with default underwear and hair (the gas mask is part of the body mesh and can be hidden with the toggle), lit outside the game engine, so colours are close to but not identical to in-game lighting. Each model has its own voice set of about 360 clips in English and Japanese; five samples of each are included here. The 3D view uses the same meshes with textures reduced to 1024 px. The game has 24 taunt animations and each model stores the id of one of them; ids step by three, so the two after it are listed as that model's as well, which is an inference rather than something the data states. Taunts reuse the ordinary voice clips; there are no separate taunt lines. A taunt button plays that taunt's voice clips and sound effects at the moments its animation triggers them.
