LET IT DIE Fighter Models

The game never shows a name for its 16 fighter bodies. This page pairs each internal model id with what it looks like, rendered from the game's own meshes and textures.

Gas mask

Labels such as "Female 3" match the model picker in the LET IT DIE save editor; the id underneath is the master_body key stored in the save. Renders show the base body in its reference pose with default underwear and hair (the gas mask is part of the body mesh and can be hidden with the toggle), lit outside the game engine, so colours are close to but not identical to in-game lighting. Each model has its own voice set of about 360 clips in English and Japanese; five samples of each are included here. The taunt type is the id stored for the model, not a decoded animation.
